# Biomecraft Demo

Windows demo of **Biomecraft**, a PCG biome and ecosystem tool for Unreal Engine 5.6 to 5.8: you drop your own meshes
into a biome's layers and it places them by slope, height, moisture, sunlight and water. The demo is the plugin's own
showcase, packaged as a Shipping build with UE 5.8.

**Download:** [BiomecraftDemo_Win64.zip](https://github.com/filipetessaro/biomecraft-demo/releases/latest/download/BiomecraftDemo_Win64.zip)
(920 MB). Windows 64-bit, DirectX 12. No engine needed.

Unzip it anywhere and run `BiomecraftDemo.exe`. You start at the edge of a meadow clearing in a 1 km valley covered by
one ecosystem area.

| Key | What it does |
|---|---|
| WASD + mouse | Fly |
| Q / E | Down / up |
| 1 to 8 | Viewpoints: clearing, riverbank, under the canopy, across the valley, from above, trail, grass, hillside trail |
| H | Hide the help text |
| Esc | Quit |

The top lines show the area under the camera and the frame time.

The trees, plants and rocks are CC0 models from Poly Haven. They are in the demo only, not in the plugin: Biomecraft
places your own meshes.
